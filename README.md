# 🎇 Diwali Sales Analysis

## 📌 Project Overview

This project analyzes Diwali sales data to uncover customer purchasing behavior, sales trends, and business insights. The analysis was performed using **Python** for data cleaning and exploratory data analysis (EDA), and **Power BI** for creating interactive dashboards and visualizations.

The goal of this project is to help businesses understand customer demographics, identify high-value customer segments, and make data-driven decisions for future marketing and sales strategies.

---

## 📌 Key Insights

- Female customers contributed more to total sales than male customers.
- Customers aged **26–35 years** made the highest number of purchases.
- Married customers were among the major contributors to sales.
- Uttar Pradesh, Maharashtra, and Karnataka generated the highest sales.
- The Food, Clothing, and Electronics categories were among the top-performing product categories.
- IT, Healthcare, and Aviation professionals were significant customer segments.
